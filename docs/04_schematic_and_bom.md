回路図の描き方（v0.2、2026-11-01 改訂）:
- 各ブロック内の接続は**線で描いている**。
- 電源は電源シンボル（`GND`、`VBAT`、`+2V5`）で表している。
- ネットラベルを使っているのは、次の箇所だけ。
  - ブロック間をまたぐ信号（例: `MICP1`、`PTT_N`、`HPL1`、`AIL2`、`LINK_EN`）
  - BM83 のピン
  - ピンヘッダー
- **配線の自己検証**: `gen_v0.py` は、各部品に持たせた「意図したネット」と、描いた配線から kicad-cli が出力したネットリストを突き合わせる。1 か所でも食い違うと異常終了する。今回の出力では全ネットが一致した。
- 未使用のピンには NC フラグを付けている。
- KiCad 8 以降で開くと形式変換の確認が出るが、そのまま変換して問題ない。
- 生成スクリプトは 2 つのファイルに分かれている。
  - `hardware/tools/kigen.py`: 汎用部分（配線の分割、ジャンクションの自動付与、ネットリスト照合）
  - `hardware/tools/gen_v0.py`: 設計データと配置

## ブロックごとの設計内容

### 電源
```
14500 → Q1 AO3401A（逆接続保護）→ SW1（スライドスイッチ）→ VBAT → U1/U2 の BAT_IN、U3 の LDO
```
- Q1: ドレインを電池側、ソースを負荷側にし、ゲートは R1（100 kΩ）で GND に落とす。電池を逆に入れると、FET もボディダイオードも導通しない。
- ADAP_IN は書き込み用ヘッダー（J2/J3 の 5 番ピン）にだけ出している。**書き込みのときは SW1 を OFF にして、5 V を ADAP_IN に入れる**。SW1 が ON のままだと、内蔵充電器が 14500 を充電する可能性がある。

### マイクのバイアス（D1）
```
VBAT → U3 TLV75525（2.5 V）→ R2 1 kΩ / C5 10 µF（fc ≈ 16 Hz）→ JP1 → R3 2.2 kΩ → MIC
```
- JP1 は既定で 1-2 を短絡（自前バイアス）。2-3 に付け替えると BM83 の MICBIAS を使う（比較試験用）。

### マイク入力（D3、Microchip リファレンスどおり）
- MIC → C7（47 nF）→ MICP1。
- MIC_RET（Ring2）→ C8（47 nF）→ MICN1。
- MIC–MIC_RET 間に C9（220 pF）。
- MIC_RET は、R4（0 Ω）を介してジャックの直近 1 点で GND に落とす。

### PTT 検出（D2）
- MIC → R5（100 kΩ）/ C10（100 nF）→ U4 TLV7041 の IN+。
- IN− には、R6（2.2 MΩ）/ R7（390 kΩ）で作った約 0.38 V のしきい値を入れる。
- 出力（PTT_N、オープンドレイン）は U1 の P0_2 へ。P0_2 の既定の割り当ては PLAY/PAUSE なので、**AVRCP の再生/一時停止として出力される見込み**（[DS] p.14）。
- 実測した ON 抵抗 1.25 Ω から、押下時の電圧は約 1.4 mV と見込める。普段は約 1.5〜2 V（仮）。
- SW2 は PTT と並列につないだ試験用ボタン。R8 はヒステリシス用（DNP）。

### BM83 #1（U1）
- MFB（SW3）は SYS_PWR に引き上げるアクティブハイ。ESD 対策に D2 と C14（15 pF）を付けている（リファレンスどおり）。
- LED は SYS_PWR から LED1/LED2 ピンへ直結する（電流は Config Tool で設定）。
- 使っていない GPIO はすべて J4（2×8）に、I2S は J5 に引き出している。
- P2_3 は LINK_EN として使う。

### 音声出力（D10、D5）
- **Config Tool の Speaker Output を "Single End" に設定する前提**。AOHPM は未接続。
- U1 の AOHPL/R → C20（4.7 µF）→ R10（10 kΩ）で GND → R11（1 kΩ）/ C21（470 pF）→ C22（10 µF）→ U2 の AIL/AIR（ライン入力の回路はリファレンスどおり）。
- U1 の AOHPL/R → C26/C27（100 µF）→ SW4（ディップスイッチ）→ ジャックの T/R1（エアチューブイヤホン）。R16/R17 はポップノイズを減らすためのブリーダー抵抗。

### BM83 #2（U2、AT ファームウェア）
- MFB（SW5）の長押しで OpenRun を探す（[AN] p.30）。
- JP2 で Aux-in 検出（P3_2）の扱いを選ぶ。1-2 は常時検出（GND）、2-3 は U1 の LINK_EN と連動（D11 案）。
- J6 に GPIO を引き出している。AT ファームウェアの送信/受信の切り替えや入力ソースの切り替えに使う GPIO は、Config Tool で確認したうえで、ここでジャンパーを使って固定する。

## 発注前に確認すること（未確認項目）

| # | 項目 | 確認方法 |
|---|---|---|
| C1 | BM83 のフットプリント寸法（パッドの大きさ、pin 56/57 の位置、アンテナのキープアウト形状） | DS70005402H の Fig.8-2 と、実物またはメーカーの CAD データで照合する |
| C2 | TLV75525 と TLV7041 のピン配置（KiCad 標準ライブラリのシンボルに従っている） | TI のデータシートで照合する |
| C3 | Keystone 2460 に保護回路付きの 14500 が収まるか | ホルダーの寸法と、セルの全長（50〜53 mm）を比べる |
| C4 | GPIO の内部プルアップの有無（PTT_N と SW2 のアクティブロー入力が前提にしている） | Config Tool または EVB のユーザーガイドで確認する。プルアップがなければ、外付け抵抗の追加を検討する（VDD_IO は外部に接続できない点に注意） |
| C5 | U1 の外部アンプイネーブル信号を P2_3 に割り当てられるか、その論理 | Config Tool で確認する |
| C6 | U2 の AT ファームウェアの GPIO 割り当て（送信/受信、Aux/I2S） | AT パッケージの設定ファイルで確認する |
| C7 | -00TA/-00TB に AT ファームウェアが書き込まれているか | 購入元の型番説明で確認する。書き込まれていなければ、isUpdate で書き込む |
| C8 | SK1（温度検出）を未接続にしたときの挙動。内蔵充電器を使わないので影響しない見込み | 段階 1a で確認する |
